# Brag Plan: Algorithms from Scratch in TensorFlow

## What is this app?
A source-first learning repository that turns computer-vision, natural-language-processing, and reinforcement-learning ideas into executable TensorFlow programs.

## The angle
Treat the repository like a living research bench: begin with the intimidating phrase “from scratch,” open it into three distinct disciplines, then prove that the code produces tangible artifacts. The confidence comes from showing real local outputs, not invented benchmark claims.

## Hook (first 2-3 seconds)
“DON'T JUST IMPORT THE IDEA.” lands over a precise tensor-grid motif, followed by the handwritten-feeling correction: “trace it.”

## Key moments (the middle)

- The repository map fans out into Computer Vision, NLP, and Reinforcement Learning.
- Three real local artifacts arrive in sequence: Progressive GAN samples, an image-captioning validation grid, and RL training/evaluation plots.
- TensorFlow primitives from the README resolve into a compact source-flow: tensors → losses → updates → behaviour.

## Outro / punchline
“Algorithms from Scratch in TensorFlow” lands with “See the mechanics. Build the intuition.”

## User flow worth showing
Choose a family → inspect its tensor-level implementation → run it and inspect the generated artifact. This is a repository rather than a GUI, so the flow is represented through its documented structure and real local run outputs.
